# Revoke Allowances (Deprecated)

`revokeAdapterAllowances` is no longer available in Gearbox V3.1 `ICreditFacadeV3Multicall`.

## Notes

- V3.1 docs should not include allowance revocation as a multicall operation
- Existing account automation should rely on currently supported operations
