# Enabling and Disabling Tokens (Deprecated)

`enableToken` and `disableToken` are no longer available in Gearbox V3.1 `ICreditFacadeV3Multicall`.

## Use These Instead

- For collateral token activation/deactivation, use [Updating Quotas](./updating-quotas.md) via `updateQuota`
- For access control automation, use [Setting Bot Permissions](./set-bot-permissions.md)
- For broader multicall operation coverage, use [Multicall Operations](./README.md)
